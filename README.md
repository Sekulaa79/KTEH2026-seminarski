# Aplikacija

Web aplikacija za planiranje putovanja. Korisnik pomocu unetih filtera dobija preporuku destinacija koje bi mogao da poseti, ukoliko je ulogovan destinacije moze dodati na svoj profil kako bi imao uvid u planiranja putovanja.

## Funkcionalnosti

* SessionStorage za cuvanje podataka
* Filtriranje u realnom vremenu
* Paginacija
* Sprecavanje duplikata
* Prosledjivanje stanja
* Kontrola pristupa

## Tehnologije

* React
* Typescript
* React Router DOM
* React Context
* SessionStorage
* Git
* Css
